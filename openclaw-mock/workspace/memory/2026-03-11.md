## 飞书文档 API 调用经验

### ✅ 正确的 API 调用方式

**创建文档并写入内容的流程**：

1. 获取 token: `POST /open-apis/auth/v3/tenant_access_token/internal`
2. 创建文档: `POST /open-apis/docx/v1/documents` with `{ title: "xxx" }`
3. 写入内容: `POST /open-apis/docx/v1/documents/{docId}/blocks/{docId}/descendant`

**关键点**：
- API 路径是 `/descendant`（单数），不是 `/descendants`（复数）！
- 请求体格式：
  ```json
  {
    "children_id": ["block_id_1", "block_id_2", ...],
    "descendants": [
      { "block_id": "block_id_1", "block_type": 2, "text": { "elements": [...] } },
      ...
    ]
  }
  ```
- block_id 需要自己生成，格式如 `doxcn_${timestamp}_${index}`

### ❌ 错误的调用方式（返回 404）

以下 API 路径都返回 404：
- `/open-apis/docx/v1/documents/{docId}/blocks/{docId}/descendants/batch_create`
- `/open-apis/docx/v1/documents/{docId}/blocks/{docId}/children/batch_create`
- `/open-apis/docx/v1/documents/{docId}/blocks/{docId}/children/insert`
- `/open-apis/docx/v1/documents/{docId}/blocks/batch_create`

**原因**：这些是旧的或错误的 API 端点

### 飞书应用权限要求

文档操作需要以下权限：
- `docx:document` - 文档基础操作
- `docx:document:readonly` - 读取文档
- `docx:document.block:convert` - 块操作（写入内容必需）
- `drive:drive` - 云空间
