### 🔧 实现细节

**文档创建流程：**
```javascript
// 1. 获取 token
const token = await getAccessToken();

// 2. 为每个模块创建文档
for (const mod of modules) {
  const docId = await createDocument(token, title, content, owner_open_id);
  await addBlocks(token, docId, blocks);
}

// 3. 推送带按钮的消息
curl -X POST webhook -d '{
  "card": {
    "elements": [
      { "actions": [ /* 按钮 */ ] }
    ]
  }
}'
```

**关键配置：**
- `owner_open_id`: 设置文档所有者，解决权限问题
- `block_type: 2`: 简单文本块，避免复杂格式
- `max 40 blocks`: 每个模块限制在飞书 API 范围内
- `button limit`: 每行最多 3 个按钮
